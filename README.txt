HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in your browser.

HOW TO PUBLISH FOR FREE (GitHub Pages)
1. Sign in to GitHub and create a new public repository (for example: sagar-portfolio).
2. Upload index.html, style.css, script.js, and profile.jpg to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. Wait for the published URL shown in Settings > Pages.
